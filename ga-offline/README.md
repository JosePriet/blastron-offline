# Global Assault Offline

An offline, single-player build of Kongregate/Synapse Games' **Global Assault** (Android 1.30.1). The game's servers
are gone; this build answers every server call inside the app, from a local save, so the campaign, store, upgrades,
fusion, Research Lab, Generator, objectives and equipment work with no network.

## Play on Android

1. Uninstall any original Global Assault (the signature differs).
2. Install `global-assault-offline.apk` (allow installs from unknown sources).
3. Start the game. No account or connection is needed.

The save is `Android/data/com.kongregate.mobile.globalassault.google/files/ga_offline/save.json`. Copy it to keep a
backup; deleting it starts a new game.

## Play on Windows

The game is Android-only (there is no Windows version of the 1.30.1 app), so run the APK in an Android emulator:

1. Install **BlueStacks 5** (https://www.bluestacks.com) or **LDPlayer 9** (https://www.ldplayer.net).
2. Drag `global-assault-offline.apk` onto the emulator window, or use its "Install APK" button.
3. Open Global Assault from the emulator's home screen. Mouse clicks work as taps; drag units with the mouse.

If the game shows a black screen, switch the emulator's graphics renderer (OpenGL / DirectX) in its settings and
restart it.

## What is original and what is ours

- Unit stats, missions, enemy decks, campaign rewards, Research Lab tables, fusion recipes and equipment come from the
  archived game files and the archived Global Assault wiki.
- Values that were only on the server and are lost (drop odds, Volt Coin prices of the higher drop tiers, component
  drop rates, a few recipes) are ours. The full list is in the change log that accompanies each release.
- PvP is locked: there is no one to fight offline.

## Build from source

Needs the original `Global+Assault_1.30.1` APK, a keystore, the .NET 8 SDK, Python 3 and Java.

    ./build.sh Global+Assault_1.30.1.apk keystore.jks global-assault-offline.apk

`GA_TEST=1` adds the emulator test driver (`src/test`), used only by the CI emulator workflow.

- `src/server`: the local server (GAOffline.dll), patched into the game's Assembly-CSharp.dll by `src/patcher`.
- `data`: the game data embedded in the server, generated by the scripts in `tools` from the archived sources.
- `tests`: the emulator test seed and scripts.
